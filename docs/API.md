# ShaderLab API

This reference covers the current Schema 2.0 runtime and Vite integration.

## Entry Points

| Import | Purpose |
| --- | --- |
| `@yoruxiii/shaderlab` | Browser runtime API: `shader_frame` and public types. |
| `@yoruxiii/shaderlab/vite` | Vite plugin for `.slab` compilation and call-site transform. |
| `@yoruxiii/shaderlab/client` | Ambient TypeScript declaration for `*.slab` imports. |
| `@yoruxiii/shaderlab/react` | React `ShaderFrame` component and `useShaderFrame`. |
| `@yoruxiii/shaderlab/vue` | Vue `ShaderFrame` component and `useShaderFrame`. |
| `@yoruxiii/shaderlab/svelte` | Svelte `shaderframe` action. |
| `@yoruxiii/shaderlab/svelte/ShaderFrame.svelte` | Svelte `ShaderFrame` component. |
| `@yoruxiii/shaderlab/nuxt` | Nuxt module that registers the Vite plugin. |
| `@yoruxiii/shaderlab/sveltekit` | SvelteKit-friendly Vite plugin re-export. |
| `@yoruxiii/shaderlab/remix` | Remix-friendly Vite plugin re-export. |

## `shader_frame`

`shader_frame` is a proxy object. Accessing `shader_frame.<id>` creates a call function for the matching `<shader_frame id="...">` in an imported slab library.

```ts
import { shader_frame } from "@yoruxiii/shaderlab";
import fx from "./fx.slab";

const frame = shader_frame.clouds(fx) {
  depth: 0.4,
  parallax: 0.06,
};
```

The Vite plugin lowers that block to:

```ts
const frame = shader_frame.clouds(fx, {
  depth: 0.4,
  parallax: 0.06,
});
```

Arguments:

- `library`: the default import from a compiled `.slab` file.
- `options`: generated by the block syntax; contains mutable uniform overrides and `augments`.

## Augments

Spatial augments are declared in call blocks with `augment.<id>(library)`.

```ts
const frame = shader_frame.grade(fx) {
  gain: 1.2,
  augment.ripple(fx) {
    strength: 0.4,
  },
  augment.caustics(fx),
};
```

Augments execute in declaration order. Each augment must point to a `type="spatial" mode="augment"` frame. Augments are wired as:

```text
canvas_item | canvas_25d -> spatial augment(s) -> postprocess
```

## `ShaderFrameInstance`

Every `shader_frame.<id>(...)` call returns a `ShaderFrameInstance`.

```ts
interface ShaderFrameInstance {
  readonly type: "canvas_item" | "canvas_25d" | "spatial" | "postprocess";
  readonly id: string;
  readonly uniforms: Record<string, unknown>;
  mount(target: HTMLElement | HTMLCanvasElement, options?: MountOptions): void;
  unmount(): void;
  set(param: string, value: unknown): void;
}
```

Methods:

| Method | Behavior |
| --- | --- |
| `mount(target, options?)` | Creates or uses a canvas, initializes WebGL2, starts rendering. |
| `unmount()` | Stops rendering, disconnects observers/listeners, releases GL resources. |
| `set(name, value)` | Updates a mutable uniform. Sealed uniforms throw. |

`target` may be a canvas or an HTML container. If a container is passed, ShaderLab creates a child canvas.

## Mount Options

```ts
interface MountOptions {
  feedFrom?: ShaderFrameInstance;
  augments?: ShaderFrameInstance[];
  maxDevicePixelRatio?: number;
  visibilityPause?: boolean;
  visibilityRootMargin?: string;
  depthBuffer?: boolean;
  webglContextAttributes?: Partial<WebGLContextAttributes>;
}
```

Most apps should not pass `feedFrom` directly. Calling a `postprocess` frame auto-wires the upstream `canvas_item` or `canvas_25d` from the same slab. If `feedFrom` is passed to an auto-composed frame, ShaderLab warns and ignores it.

Use `maxDevicePixelRatio` for preview canvases or dense UIs where native device pixel ratio would allocate oversized framebuffers.

## Framework Helpers

React:

```tsx
import { ShaderFrame } from "@yoruxiii/shaderlab/react";

<ShaderFrame
  frame={shader_frame.clouds(fx, { depth: 0.5 })}
  mountOptions={{ visibilityPause: true }}
  uniforms={{ depth: 0.7 }}
  ref={canvasRef}
/>;
```

Vue:

```vue
<script setup lang="ts">
import { ShaderFrame } from "@yoruxiii/shaderlab/vue";
import { shader_frame } from "@yoruxiii/shaderlab";

const frame = shader_frame.clouds(fx, { depth: 0.5 });
</script>

<template>
  <ShaderFrame
    :frame="frame"
    :mount-options="{ visibilityPause: true }"
    :uniforms="{ depth: 0.7 }"
  />
</template>
```

Svelte:

```svelte
<script lang="ts">
  import { shaderframe } from "@yoruxiii/shaderlab/svelte";
  import ShaderFrame from "@yoruxiii/shaderlab/svelte/ShaderFrame.svelte";
  export let frame;
</script>

<canvas use:shaderframe={{ frame, mountOptions: { visibilityPause: true } }} />
<ShaderFrame {frame} mountOptions={{ visibilityPause: true }} uniforms={{ depth: 0.7 }} />
```

Framework helpers mount/unmount a `ShaderFrameInstance`, forward mount options, and can apply mutable uniforms declaratively. They do not import slab paths or build frame options.
